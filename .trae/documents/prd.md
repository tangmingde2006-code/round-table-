## 1. 产品概述

Round Table AI 是一个面向宗教智库构建的多智能体新闻筛选平台。通过接入 DeepSeek API，部署七位专业 AI 角色（事实核查员、立场分析师、宗教伦理评估师、传播意图分析师、深度舆情分析师、宗教敏感度审查员、综合仲裁官）进行圆桌讨论式协作分析，对输入新闻进行事实核查、立场分析、伦理评估等多维度审查，最终输出结构化入库建议与风险评级报告。

- 目标用户：宗教研究机构、智库分析师、宗教事务决策者
- 核心价值：将新闻筛选从人工判断升级为多角色 AI 协作审查，提供全面、客观、结构化的宗教相关新闻评估

## 2. 核心功能

### 2.1 用户角色

| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 分析师 | API Key 配置 | 提交新闻、查看分析报告、导出结果 |
| 管理员 | 系统配置 | 管理角色参数、查看历史记录、调整评估权重 |

### 2.2 功能模块

1. **新闻提交页**：新闻文本/URL 输入、分析参数配置、提交与启动分析
2. **圆桌讨论页**：实时展示七位角色的讨论过程、角色发言流、讨论进度追踪
3. **分析报告页**：各角色结构化输出、综合仲裁结果、风险评级可视化、报告导出
4. **历史记录页**：历史分析记录列表、搜索与筛选、报告回顾

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |

## 3. 核心流程

用户输入新闻文本或 URL → 系统预处理（提取正文）→ 依次调用六位专家角色进行各自维度分析（支持并行）→ 六位角色分析完成后，综合仲裁官汇总所有意见 → 生成最终结构化报告（含评分、风险评级、入库建议）→ 展示报告并存储到历史记录。

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**：深靛蓝（#1a1a2e）搭配琥珀金（#d4a843）作为强调色，营造庄重、学术、权威的氛围
- **辅助色**：暗紫（#16213e）、暖灰（#e8e0d0）、象牙白（#f5f0e8）
- **按钮风格**：圆角微凸，金色描边，hover 时发光效果
- **字体**：标题使用 Playfair Display（衬线体，学术感），正文使用 Noto Sans SC（中文友好）
- **布局风格**：卡片式布局，圆桌页面采用径向布局
- **图标风格**：Lucide 图标库，线性风格，金色描边
- **整体氛围**：学术殿堂感，类似古典图书馆/议事厅的视觉隐喻

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI 元素 |
|----------|----------|---------|
| 新闻提交页 | 新闻输入区 | 深色背景文本框，金色边框，左上角装饰性花纹 |
| 新闻提交页 | 参数配置面板 | 折叠式面板，角色头像选择器，滑块控件 |
| 圆桌讨论页 | 圆桌可视化 | 中心圆桌 SVG，七角色环绕排列，发言时脉冲动画 |
| 圆桌讨论页 | 实时讨论流 | 竖向时间线，角色头像+气泡卡片，打字机效果 |
| 分析报告页 | 角色分析卡片 | 六宫格卡片，每卡含角色图标+评分+关键发现 |
| 分析报告页 | 综合仲裁面板 | 居中大卡片，评分仪表盘，风险等级色带 |
| 分析报告页 | 雷达图 | SVG 六维雷达图，金色填充区域 |
| 历史记录页 | 记录列表 | 表格式布局，行 hover 高亮，风险等级色标 |

### 4.3 响应式设计

- 桌面优先设计，针对 1280px+ 宽度优化
- 平板端（768-1279px）：圆桌布局切换为列表布局，卡片从多列变为单列
- 移动端（<768px）：简化圆桌为纵向堆叠，关键操作固定底部
